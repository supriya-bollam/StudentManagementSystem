Student Management System
A simple Student Management System developed using Java and Collections Framework.
This project allows users to add, view, search, update, and delete student records through a console-based application.
📌 Project Overview
The Student Management System is a Java-based mini project designed to demonstrate:
Object-Oriented Programming (OOP)
Java Collections Framework
CRUD operations
User input handling
Searching and updating records
Basic project structure
The project does not require a database. Student data is stored temporarily using Java Collections.
🛠️ Technologies Used
Java
OOP Concepts
Collections Framework
ArrayList
HashMap
Scanner for user input
✨ Features
Add Student
View All Students
Search Student by ID
Update Student Details
Delete Student
Exit Application
